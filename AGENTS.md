# AGENTS.md — Portfolio

## Stack

Next.js 16.1 (App Router) — React 19 — TypeScript 5 — Tailwind v4 — Motion v12 — shadcn/ui

## Commands

```sh
npm run dev      # dev server on http://localhost:3000
npm run build    # production build
npm run start    # serve production build
npm run lint     # eslint (flat config: eslint.config.mjs)
```

No test framework. No typecheck script (rely on `tsc --noEmit`).

## Project structure

- `src/app/page.tsx` — single-page home composing all sections (Navbar, Hero, About, Services, Skills, Projects, Contact, Footer)
- `src/app/projects/[id]/page.tsx` — dynamic project detail page; project data is **hardcoded** in that file
- `src/components/` — section components; `src/layout/` — Navbar, Footer; `src/app/` — root layout & pages
- `@/` path alias maps to `./src/*` (from tsconfig.json `"@/*": ["./src/*"]`)
- All source lives under `src/`

## Key conventions

- All components are `"use client"` except `src/app/layout.tsx` and `src/app/page.tsx`
- Dark mode uses **next-themes** (`ThemeProvider` with `attribute="class"` in root layout, `useTheme()` hook in Navbar)
- Animations use `motion` (from `"motion/react"`, not `"framer-motion"`)
- Contact form uses **EmailJS** (`@emailjs/browser`) with hardcoded keys in `ContactMe.tsx`; no `.env` file
- CSS: `@import "tailwindcss"` + CSS variables for light (`:root`) / dark (`.dark`) in `src/app/globals.css`; dark variant via `@custom-variant dark`
- Font: Poppins via `next/font/google` in root layout
- Same-page scroll nav uses `react-scroll` (`Link` from `react-scroll`, not `next/link`)
- shadcn/ui components in `src/components/ui/` (button, card, input, textarea); `cn()` utility in `src/lib/utils.ts` uses `clsx` + `tailwind-merge`
- Two unused components commented out in `page.tsx`: `Education` and `HeroSection1` (alternative hero variant)
- Two project list components: `src/components/Projects.tsx` (homepage section) and `src/components/Pages/Projects.tsx` (full `/projects` page)
- Project images are external URLs (postimg.cc)
- `next-env.d.ts` is gitignored (auto-generated by Next.js)
